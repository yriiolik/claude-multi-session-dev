# 独立 worker 协议

只执行本卡授权范围，不再派子智能体。开工及压缩恢复按本卡阅读地图：当前卡→相关原文锚点→本卡事实/用例/契约版本→必要交接与资产状态；不全仓扫描或通读历史。
遵守实际工作树与子目录适用的 AGENTS.md 及其引用规则，不把聊天摘要当唯一需求。
当前 `<module>.task.md` 是唯一生效卡；核卡片版本/哈希，不沿历史任务卡拼接要求。发现聊天备注与当前卡冲突，
先报告冲突并继续不受影响事项，不自行认定“最新一句覆盖全部”。任务目标变更需完整新卡和受影响验收条件确认。
本轮未结束又收到独立新目标时，说明应另建任务，不默默排队或切换目标；本任务必要澄清/解除阻塞正常承接。
需求变更的停点通知只要求保存现场并安全结束本轮，等待完整新卡，不在原卡下执行新要求。

## 执行与验证

- developer：实现前提出本轮可交付行为和验证方式，确认独立验收者已审定完成条件；未变条件沿用已确认版本。
  在卡片授权内负责定位、处理、自测、交接与相关回修，缺权限只交具体阻塞和可行选项，不把整个调查退回主端。
  代码在隔离 worktree 开发，非代码写独立产物目录；相关定向自测，代码提交后执行本技能 `scripts/cc-fleet-land <RQ>`，只合入本地集成分支；非 Git 产物记录版本/内容哈希和证据，不伪造提交。
- verify/integ author：先对照原始需求审定实现者提出的完成条件，明确实际入口、预期、不通过条件和证据，持久化后及时交接；
  再独立编写验收脚本/夹具/清单；Git 资产提交但暂不 land，非 Git 资产保存版本/内容哈希；不等待开发，tests 可 not-run，
  evidence 指向脚本与用例映射。收到 execute 后保留验收资产：代码合并最新集成基线，需交付的脚本提交并 land，再测最终集成 SHA；非 Git 按来源/产物版本与内容哈希验收真实入口，不要求 Git 操作。
- verify/integ execute：不改业务代码或放宽断言；真实页面先连续跑主流程，再逐项验证适用分支/异常、幂等与事务。
  API/单测/mock 自家业务接口不能替代页面；确无页面入口记录理由及实际入口。逐例保存操作、结果、截图/trace、SHA 和环境。
  缺陷交复现步骤、预期/实际、验收版本、证据与原负责人，供定向回修；不把详细排障交主端重做。
- regression：在约定集成 SHA（非 Git 用产物版本/内容哈希）上按给定去重范围统一执行，不自行扩到全量。与 verify 合并承担时分阶段记录。
- scout/研究：提交可复现结论、来源和反例；精确 ID/路径先核身份和原字段。核真实 schema/语义；缺源前检查已配置的相关库/镜像。
  自测包含会改变结论的去重、单位/分母、时期或范围不可比、缺证等反例。研究样本仅是本次输入，不能硬编码生产白名单/答案。

开发自测默认仅本卡相关最小集合，E2E ≤6 spec 且 ≤15 分钟；超预算列待回归，不偷偷跑全量。
任务卡没给范围时用 `cc-fleet-e2e-scope suggest --base fleet/<RQ>` 推导裁剪；跑后 record 实际范围。
E2E 前后通过 `cc-fleet-e2e-lock acquire/release <COORD> <module>` 协调共享资源；regression 默认 exclusive。
锁等待使用短有界 --wait；stale 只提醒核实，不证明持有者死亡，不自动抢锁；纯远端等待仅在确认不再写共享资源后释放自己的锁，需要共享操作再获取，禁止强解他人锁。

本卡负责的异步业务尚在运行时持续有界等待，accepted/首轮返回不等于最终结果。只有实际失败或真实外部阻断才交 failed/blocked。
真实小样本须贯通到最终产物和业务判断，结构绿/零外研不能冒充成功；最终仍完成全部指定范围。
共享事实按本卡指定唯一维护者更新；提交证据、未知项与失败尝试供其它卡引用，不重复已有效调查。
不 reset --hard、不推远端、不擅自合共享分支、删除或清理 worktree。

## 输入与回执

业务澄清交主端汇总，不自行调用 request_user_input / request_user_input_async / AskUserQuestion 弹卡，也不越过主端向用户求答。
已有授权能决定就继续；确缺必需输入先做独立工作，再 result=blocked，needsInput 给问题、选项/推荐、影响和已查来源。
强制审批仍走宿主真实通道，调用前 commentary 说明动作、原因、操作入口；不能代批、改权限或用普通消息冒充批准。
异步提问返回不表示已有答案；旧问题解决后记录已解除及当前真实阻塞，避免重复提问。

回执中的 agent_id 必须从已登记的本轮名册 agentId 读取，不猜环境变量或把 App ID 当 agent。未登记向主端报告身份待登记。
新建默认显式 fork_context=false；true 仅复制主端当前历史，不复制旧 worker 历史；reuse 保留你自己的历史，优先沿已验证事实/失败尝试续做。
即使继承主端历史，你仍是本卡 worker；历史 PM 编排指令、旧任务及旧授权不能覆盖当前卡、扩大写入范围或授权递归派发。
fresh 是换身份，按新建策略选择是否继承；为清除旧假设时 false。继承不替代完整任务卡、完成条件、写入范围及资产交接。
独立验收执行（verify/integ/regression 且 phase != author）用 false；author 准备可按收益选择，继承过主历史的 author 进入 execute 须 fresh false。
每轮先写任务前缀指定的 attempt 专属 handoff（建议 ≤80 行）：
原始需求/用例/事实/契约版本、失败尝试与未知项、已实现/未实现项、worktree/提交/合入 SHA（非 Git 为产物版本/内容哈希）、环境与必要命令、验证证据、当前失败/未决问题、下一步。
保留对独立验收有用的事实与证据链接，不复制聊天、完整日志或已作废猜测。
summary 写结果与是否达到本卡门槛，证据用索引；需要主端裁定的事项与技术过程分开。正常运行不反复请求新指令。
随后将完整 v2 JSON 原子写到指定 receipt；协调目录不可写时使用前缀指定的临时 inbox 与同 attempt handoff。
最后执行前缀中的 validate-receipt，检查通过再输出同一 JSON。检查只核协议与 Git 证据，业务真实性仍由独立验收判断。
最终回复必须是含当前 rq/module/attempt/agent_id、与有效回执完全一致的完整 JSON，不用摘要、null 或旧轮 JSON 替代；主端用它区分 send 后可能残留的上一轮 completed。

当前版本失败如实写 tests.result=failed 且 result=failed/blocked，不藏进 risks、改 not-run 或删断言。
已解决的历史失败放顶层 resolved_failures，保留原 command/result/evidence、修复 SHA 与当前复验引用；当前 tests 仅列当前检查。
必需入口、算法、判断或校验仍待实现即未完成；按预期实现并验证的 unknown/gap 是业务结果，不能冒充业务成功。
开发 done 表示本卡实现及定向测试已交付，不等待下游 verify 形成环；契约替身自测不等于真实联调完成。
只修正回执字段且代码/配置/测试基线未变时，引用仍有效证据，不重新跑整套测试；证据失效则按范围复测。
